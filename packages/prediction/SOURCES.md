# Sources

Reviewed 2026-10-08. These procedures are original Galleon guidance based on maintained primary documentation; no upstream CLI or signing implementation is bundled.

- [Polymarket CLI](https://github.com/Polymarket/polymarket-cli): public JSON market/book commands, experimental status and wallet-enabled command boundaries.
- [Market discovery](https://docs.polymarket.com/market-data/discover-markets): authoritative version and outcome identity mapping.
- [Prices and order books](https://docs.polymarket.com/market-data/prices-order-books): book levels, observation time, state hash and both position systems.
- [Positions and tokens](https://docs.polymarket.com/concepts/positions-tokens): ledger, collateral and split payouts.
- [Resolution](https://docs.polymarket.com/concepts/resolution): UMA proposals and disputes versus Chainlink TWAP markets.
- [Onchain position data](https://docs.polymarket.com/resources/onchain-position-data): canonical ledger balances, version-specific events and payouts.

Documentation and offline tests were reviewed. Live trading, account eligibility, wallet access and redemptions were not tested. Discover current contracts and market parameters at use time.
