# Official routing providers

Primary sources accessed 2026-09-05. Documentation describes intended support; tool discovery proves only the exposed schema. No trading, signing, wallet login or paid request was tested. Recheck current versions, supported chains and fees for the actual route.

## Observed tool discovery and gaps

- **1inch:** unauthenticated initialize/tools-list succeeded, server `1inch-business` version `1.0.0`, ten tools versus documentation's nine. Additional `authenticate` appears. `swap`, `orderbook`, `product_api` and `walletconnect` are marked destructive. For public discovery, narrowly select `search`, `list_examples`, `get_example`, `aqua`. Authentication and organization-scoped debugging are separate activities even when annotated read-only.
- **Across:** unauthenticated discovery succeeded, server `mcp-server-across` version `2.0.0`, fourteen tools versus documentation's seven. Tool names include `get_supported_chains`, `get_suggested_fees`, `get_swap_quote`, `track_deposit`, `get_available_routes`, `get_limits`, and `swap_with_wallet`. No safety annotations were supplied. Exclude `swap_with_wallet` and `recrawl_docs` from read-only setup; inspect schemas for other tools before enabling them.
- **LI.FI:** official MCP initialization returned HTTP 403 in this environment. Its documentation is verified; live availability and quote behavior are unverified.
- **Jupiter:** trading MCP discovery encountered incomplete transport reads and a bounded retry timed out. The documented endpoint and auth distinction are verified; live tools and trading are not.

None of these observations proves the provider will serve the same schema later. Keep connections optional and record `documented`, `discovered`, `read-tested`, `simulated` and `executed` separately. Tool annotations are hints, not financial permission controls.
