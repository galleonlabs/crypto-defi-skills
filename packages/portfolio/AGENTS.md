# Portfolio pack

Keep this pack independently installable and every skill self-contained. Reuse official provider tools; do not implement signing or invent agent APIs. Record dated primary sources and separate documentation, tool discovery, reads, simulation and execution evidence. Skills do not grant financial or account-action authority. Run `bun run check` and `validate-agent-skills skills`; parent integration runs root checks and the clean package consumer smoke. Shared build tooling is bundled into each published CLI, with no runtime dependency on the monorepo.
