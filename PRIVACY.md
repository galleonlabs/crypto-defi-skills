# Privacy

The packs in this repository are instructions and local helpers that run inside the agent you install them in. Galleon Labs operates no server for them, collects no telemetry, and does not receive or store prompts, accounts, wallet addresses or credentials.

When a skill reads data, the request goes from your agent directly to the provider you or your agent choose, such as CoinGecko, DefiLlama, an RPC endpoint or a protocol's official API, under that provider's privacy policy. Those requests disclose ordinary network metadata and the identifiers you look up. Optional API keys stay in your environment and are sent only to the provider they belong to. Your agent's host (for example Anthropic, OpenAI or Google) processes your conversation under its own policy.

Do not paste secrets, seed phrases or private keys into a conversation. Report problems through [GitHub issues](https://github.com/galleonlabs/crypto-defi-skills/issues) without secrets, or [privately](https://github.com/galleonlabs/crypto-defi-skills/security/advisories/new) for security matters.
