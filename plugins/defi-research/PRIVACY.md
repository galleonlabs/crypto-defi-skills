# Privacy

This package contains instructions and a connection to CoinGecko's official public MCP. Galleon does not operate that server, collect telemetry, or store prompts, accounts or wallet credentials. Requests sent to CoinGecko are governed by [CoinGecko's privacy policy](https://www.coingecko.com/en/privacy). ChatGPT processes conversations under OpenAI's policies. Public API requests disclose network metadata and requested asset identifiers to the provider. Do not send credentials, private portfolio details or personal data to public tools.

Optional authenticated providers referenced in skills are separate connections governed by their own policies; they are not installed by this plugin. Report issues through [GitHub support](https://github.com/galleonlabs/crypto-defi-skills/issues) without secrets.
